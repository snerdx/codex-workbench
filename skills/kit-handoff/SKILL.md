# Hand off work

Read the existing handoff at docs/codex-kit/SESSION.md, or the project's established equivalent. Preserve its structure, unrelated active work, and existing user edits. If the task is read-only, return the handoff in chat unless saving it is explicitly requested.

Verify current repository state. Record date/time/timezone, branch and commit or Git unavailability, changed files, pre-existing work, completed and partial behavior, blockers, and the next actionable step. Include exact commands, working directories, observed results, and reasons checks were not run. Never invent coverage, commits, approvals, or test results. Keep credentials and sensitive data out.

Promote durable decisions into the project's authoritative profile or decision log and link them. Distinguish authorization already given from actions still requiring a decision. Do not turn session history into permanent policy. Finish with the highest-priority next action and unresolved risks.
