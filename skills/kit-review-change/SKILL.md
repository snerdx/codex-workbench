# Review a change

Read [review procedure](references/review.md) and the project's AGENTS.md. Inspect the requested scope, relevant callers, and tests. Review is read-only unless the user explicitly requests fixes or a saved report. Do not update session files as a side effect. State evidence and uncertainty; an empty findings list is valid.
