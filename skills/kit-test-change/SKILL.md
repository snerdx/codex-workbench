# Test a change

Read [testing procedure](references/testing.md), the project's AGENTS.md, and its command registry when present. Establish intended behavior from requirements rather than treating current implementation as the oracle. Edit scoped tests, fixtures, and test configuration; report production defects for authorized implementation. Execute appropriate checks and report actual results and gaps.
