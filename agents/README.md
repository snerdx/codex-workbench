# Workflow migration

The former role prompts are now discoverable skills. Use [the quick start](../README.md) to install them into a project. Existing agent-* paths remain as bookmarks pointing to maintained skill entrypoints.

| Workflow | Skill |
|---|---|
| Initialize a project | [$kit-project-init](../skills/kit-project-init/SKILL.md) |
| Implement a change | [$kit-implement-change](../skills/kit-implement-change/SKILL.md) |
| Read-only review | [$kit-review-change](../skills/kit-review-change/SKILL.md) |
| Tests | [$kit-test-change](../skills/kit-test-change/SKILL.md) |
| Refactor | [$kit-refactor](../skills/kit-refactor/SKILL.md) |
| Documentation | [$kit-document-change](../skills/kit-document-change/SKILL.md) |
| Handoff | [$kit-handoff](../skills/kit-handoff/SKILL.md) |

Explicit invocation improves repeatability. Automatic selection remains enabled. A skill is a workflow, not a separate reviewing person or additional execution authority. Do not spawn agents unless requested or otherwise authorized by applicable instructions.
